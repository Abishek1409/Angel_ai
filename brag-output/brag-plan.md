# AngelAI — brag plan

What it is: a private workspace where you upload PDFs/TXT files and chat with them, then get AI-generated flashcards and a flowchart of the document.
For: students and anyone studying from long documents.
Angle: one document, three ways to learn it (chat, flashcards, flowchart), shown in the real UI.
Hook: "Ask your documents anything." punched in one word per beat.
Punchline/outro: AngelAI logo + "Chat, flashcards and flowcharts from your own documents."
Tone: default (punchy, clean, soft transitions).
Identity: real app CSS (bg #f7f5f2, text #1a1714, accent #c96442, Inter), real layers logo, real Mermaid render.
Format: 1920×1080, 30fps, 21s. Music: 120 BPM (beat 0.5s), C–Am–F–G, every cut on a beat.

Privacy: all document names, conversation titles, questions and answers are fictional stand-ins (cell-biology study notes). No URLs, keys or user data.

## Storyboard

| Time | Scene | Content |
|---|---|---|
| 0.0–2.5 | Hook | "Ask your documents anything." word per beat, file icon drops in |
| 2.5–6.0 | Reveal | Logo draws, "AngelAI", "Your private workspace for asking better questions." |
| 6.0–9.0 | Upload | Pick cell-biology-notes.pdf → Analyze → Uploading → Ready (chime). "Drop in a PDF." |
| 9.0–13.0 | Chat | Question typed, sent, thinking dots, answer with Sources. "Ask it anything. Get cited answers." |
| 13.0–16.0 | Flashcards | Tab click, card flips Q→A. "Flashcards, generated for you." |
| 16.0–18.5 | Flowchart | Tab click, Mermaid nodes pop in on 8th notes. "Your whole doc, as a flowchart." |
| 18.5–21.0 | Outro | Logo + name + tagline, final chord rings out |
